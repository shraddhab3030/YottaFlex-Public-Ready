and extracted here on Phase 01 resumption (initial snapshot had none):

1. `problem-statement.md` - full candidate-supplied portal/email transcription.
2. `YottaFlex AI Candidate Project-FAQ.pdf` - one page, all Q1-Q12 read.
3. `YottaFlex AI Candidate Project Submission Guidelines.pdf` - one page, all sections read.

All verified readable, hashed, read completely; both PDF pages rendered and
visually inspected. Exact source identities/coverage: ../phase01/sources.json.
The problem statement is treated as challenge specification per user direction;
PDFs add submission requirements. No authenticated portal check was performed.
Source instructions do not authorize later-phase actions now. Conflicts and
assumptions: ../phase01/risks-and-decisions.md.

Raw sources remain ignored to avoid publishing private application identifiers
or source material inadvertently. This README is intentionally trackable. A
fresh checkout needs the user's three private source files to pass source-identity
checks; no source is downloaded automatically and no placeholder is acceptable.
